# Fedora Sway (based on the Butterbian sway-setup)

This is a best-effort Sway port to Fedora of Drew's`sway-setup`, which is part of the [JustAGuy Linux](https://justaguy.dev/drew) window manager collection — installable standalone or via [butterknife](https://justaguy.dev/drew/butterknife), the installer for [Butterbian](https://butterbian.org)..

## Quick Install

```bash
git clone https://github.com/theamazingbman/sway2.14-setup.git
cd sway2.14-setup
chmod +x install.sh
./install.sh
```
